GB STUDY — Power Admin + Fast Links

Features:
- Existing GB STUDY dark UI, logo URL /425 and Telegram popup icon URL /90 retained.
- Admin embedded inside index.html; open with 5 quick taps on the GB logo, then enter the existing demo PIN GBADMIN2026.
- Admin supports add/edit/hide/delete, Free/VIP, icon URL/upload, per-site open mode, Telegram popup settings, JSON backup/restore, and bulk adding.
- Maximum 100 websites/batches. Bulk format per line: Name | https://URL | https://ICON-URL | Category | internal/external/new
- Card clicks use a delegated immediate click handler, faster tap styling, and lazy/async icon loading.

IMPORTANT:
This is a static single-file app. Admin PIN is client-side/demo protection only, and settings are stored in this browser's localStorage. They do not sync to every visitor. For secure multi-user admin and shared updates, a backend/database with server-side authentication is required.

Deploy: Upload the complete site folder containing index.html to your chosen static host. Keep a backup of the old file first.
